# Raíces del Sur Lodge 🌲

Sitio web contemporáneo y minimalista para el complejo de cabañas **Raíces del Sur Lodge**, ubicado a orillas del Lago Rosselot en la Patagonia chilena (Carretera Austral, Región de Aysén).

## 🛠️ Stack Tecnológico

- **Frontend:** [React 19](https://react.dev/)
- **Lenguaje:** [TypeScript 5.9](https://www.typescriptlang.org/)
- **Bundler & Dev Server:** [Vite 8](https://vitejs.dev/)
- **Gestor de Paquetes:** [pnpm](https://pnpm.io/)
- **Estilos:** Vanilla CSS (Tokens de diseño / Brutalismo minimalista)
- **Componentes Headless Accesibles:** Radix UI
- **Formularios & Validación:** React Hook Form + Zod
- **Optimización de Assets:** Formato `.avif` nativo y lazy loading
